# 農田日記 — 品牌方向與暫定設計系統（DESIGN_SYSTEM）

> 狀態：暫定。圖示為可替換的佔位設計，不是正式商標。色票對比已以 WCAG 2.x 公式計算（見 §4）。
> 最後更新：2026-10-20

## 1. 三個方向

| | A「田埂手帳」 | B「晨光田區」 | C「家常協作」 |
| --- | --- | --- | --- |
| 概念 | 一本放在農舍桌上的田間筆記本；紙張米色、墨綠字、土色點綴 | 清晨陽光下的田：高對比、明亮、乾淨，像戶外標示牌 | 家人一起看的行事曆：圓角、暖色、親切插畫 |
| 優點 | 「日記」語意清楚、可信、有溫度；不限作物 | 戶外可讀性最強 | 對長輩與家人最親切 |
| 風險 | 若太復古會像紙本工具而非協作 | 容易冷硬、像工具軟體 | 容易幼稚，降低「資料可信」感 |
| 圖示 | 筆記本頁面 + 田畦線 + 一株新芽 | 太陽弧線 + 田畦 | 兩個圓頭人形 + 葉子 |

**推薦：A「田埂手帳」為品牌主軸，介面採 B 的戶外高對比規則。** 品牌傳達「日常紀錄、可信」，介面確保日照下可讀。

## 2. 暫定圖示

- 向量來源：[`design/brand/app-icon-placeholder.svg`](../design/brand/app-icon-placeholder.svg)（1024×1024，純幾何、無文字、無外部素材）。
- 概念：圓角方形米色底、深綠筆記本頁面、三條彎曲田畦、右上一株兩葉新芽。不含中文字（小尺寸無法辨識）。
- 單色版與通知圖示：取「新芽 + 田畦」，留待正式設計。

## 3. 圖示產製流程（尚未執行）

單一 SVG **不等於**平台發布配置完成。正式流程：

1. 以 SVG 為母版，於向量工具中為各平台調整（Android 前景需在 adaptive icon 安全區內；iOS 不可有透明背景）。
2. Android：Adaptive icon（前景層 + 背景層 + 單色層用於主題圖示），用 Android Studio Image Asset 或 `flutter_launcher_icons` 產生 `mipmap-*`；確認 `ic_launcher.xml`。
3. iOS：`AppIcon.appiconset` 1024×1024 不透明 PNG（新版 Xcode 可單一尺寸自動縮放，深色／著色變體依當期 Xcode 規格）。
4. 啟動畫面：Android 12+ SplashScreen API（圖示 + 背景色）；iOS LaunchScreen storyboard。可用 `flutter_native_splash` 產生，須確認版本支援。
5. 在實機上檢查小尺寸辨識度、深色模式、主題圖示。
6. 商店截圖依當期規格尺寸產製（尚未開始）。

## 5. 字級

- 字型：使用系統字型（iOS PingFang TC、Android Noto Sans CJK TC），不打包字型以控制 App 大小；若需一致外觀，可評估 Noto Sans TC（SIL OFL 1.1）。
- 一律使用 `sp`／Dynamic Type，支援系統文字縮放到 200%；版面以換行而非截斷因應。

| Token | 大小 | 行高 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| `display` | 28 | 1.3 | 700 | 首頁問候、大數字 |
| `title` | 22 | 1.35 | 700 | 頁面標題 |
| `heading` | 19 | 1.4 | 600 | 卡片標題 |
| `body` | 17 | 1.5 | 400 | 內文（預設，比一般 App 大） |
| `label` | 16 | 1.4 | 600 | 按鈕、標籤 |
| `caption` | 14 | 1.4 | 400 | 輔助說明（最小字級，不用於重要資訊） |

## 6. 間距、尺寸、形狀

- 間距：4 的倍數，常用 8／12／16／24。
- 觸控目標：最小 48×48 dp；主要操作按鈕高 56 dp，全寬。
- 圓角：卡片 12、按鈕 12、輸入框 10、狀態標籤 999（膠囊）。

## 7. 元件規則

**按鈕**

- 每個畫面最多一個主要按鈕（實心 primary）。次要為外框，危險操作為 danger 外框且需二次確認。
- 文字用動詞：「送出回報」「確認紀錄」，不用「OK」。
- 圖示一律搭配文字。

**表單**

- 標籤在輸入框上方，不只用 placeholder。
- 必填標「必填」文字，不只用星號。
- 數量欄旁保留「原話」欄（例如「一包半」），換算結果顯示依據。
- 錯誤訊息說明原因與下一步：「沒有網路，回報已存在手機，連上網路後會自動上傳。」
- 可選欄位收在「更多資料」中（漸進揭露）。
- 送出後提供「復原」5 秒或明確的修改入口。

**卡片**

- 首頁卡片：標題、田區名稱、時間、狀態標籤、單一主要動作。
- 敏感欄位無權查看時顯示「無權查看」，不留白。

**狀態標籤**（圖示 + 文字 + 顏色，三者並用，不只靠顏色）

| 狀態 | 圖示 | 顏色 |
| --- | --- | --- |
| 已確認 | 勾 | primary |
| 待確認／需補資料 | 時鐘／問號 | warning |
| 失敗／衝突 | 驚嘆號 | danger |
| 處理中／上傳中 | 轉圈 | info |
| 已存在手機（未上傳） | 手機 | neutral |
| 尚未確認（施藥未知） | 問號 | warning，文字「尚未確認」 |

## 8. 首頁資訊架構

1. 我的田（田區卡片或地圖切換）
2. 今天要做（工作卡，含缺幾人）
3. 等我確認（回報、人員回覆、補資料）
4. 最近異常
5. 問農務助理（階段 3 之前隱藏或顯示「即將推出」，不放假功能）

底部導覽：首頁／田區／工作／紀錄／更多。
