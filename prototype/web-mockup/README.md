# 輔助設計原型（Google AI Studio 產生，非正式產品）

這個資料夾是早期用 Google AI Studio 產生的 React／Vite 網頁原型，只用來輔助討論介面與流程。

- **不是**正式的農田日記 App。正式產品是 Flutter（Android／iOS）App 與私有後端，見根目錄 [README](../../README.md)。
- 全部為示範資料與模擬畫面，沒有連接任何後端或資料庫。
- 頁面上的狀態（例如「驗收通過」「同步完成」）是寫死的示範值，**不代表任何建置、測試或部署結果**。
- 頁面中的農業數字（農藥安全採收間隔、天然災害救助門檻與每公頃金額、市場手續費等）**未經查證**，不可作為農務或申請依據。正式功能必須依當時的官方資料來源。
- 原本的「階段 9 完工交付總結」頁籤與相關檢查函式已移除，因為它宣稱「100% 查核通過、具備生產級發布條件」，與事實不符。

## 在本機開啟（可選）

需要 Node.js。

```bash
cd prototype/web-mockup
npm install
npm run dev
```

`.env.example` 中的 `GEMINI_API_KEY` 是 AI Studio 原型用的佔位值；請勿把真實金鑰提交到 repo。

此原型不再維護，正式設計以 `docs/` 為準。
